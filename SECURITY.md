# Security policy

Sparepage is a small open-source project. It has no server and stores no user data, but it does
run inside people's browsers and reads their documents, so we take security reports seriously.

## Reporting a problem

Please email **security@sparepage.app** with:

- what you found and where (the extension, the Word add-in, or a page on sparepage.app),
- the steps to reproduce it, and
- what an attacker could do with it.

Please do not open a public GitHub issue or post details until we have had a chance to fix it.

We are a small volunteer team, so we cannot promise a fixed response time. We aim to acknowledge
a report within a week, tell you what we plan to do, and credit you in the fix if you would like
that.

## What is in scope

- The Chrome extension and its Google sign-in handling
- The Word add-in and the Word file and PDF check pages
- The website at sparepage.app

Sparepage runs entirely in the browser and sends no documents to us, so the most useful reports
are about things like unexpected data leaving the browser, unsafe handling of document content,
over-broad permissions, or ways another site could interfere with the extension.

Issues in Google Docs, Chrome, Microsoft Word, or GitHub Pages themselves should be reported to
those companies.

## Supported versions

Only the latest published version receives fixes.
