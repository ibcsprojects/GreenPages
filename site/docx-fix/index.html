Fix a Word file before you print

Choose a Word .docx file. SparePage finds highlights, oversized text, wide margins, blank lines and wordy paragraphs, and fixes the ones you pick in a new copy. The file stays on your computer. Experimental

Good to know

  • The page count is an estimate. Word may lay a page out slightly differently, so check the copy in Word before you print.
  • Fields, text boxes, footnotes and section breaks are left exactly as they are.
  • Pages, Google Docs and LibreOffice can save or export a .docx too. For Google Docs itself, the Chrome extension works inside the editor.
