Install GreenPages

For Google Docs in Chrome on a computer.

Where things stand. GreenPages is not in the Chrome Web Store yet, and Google is still reviewing its sign-in. Until that finishes, only approved testers can connect it to Google Docs. To be added, open an issue with the email address of the Google account you use for Docs.

Install it

  1. Install Node.js if you do not have it.
  2. Download the code from GitHub (Code, then Download ZIP) and unzip it.
  3. In that folder, run npm install and then npm run build. This creates a folder called dist.
  4. In Chrome, open chrome://extensions and turn on Developer mode.
  5. Click Load unpacked and choose the dist folder.

Connect it to Google Docs

  1. Open any Google Doc. A round green button appears in the corner of the editor.
  2. Click it, then Connect to Google Docs.
  3. Google may say it has not verified the app. If your account is on the tester list, choose Continue, then allow access to your Docs.
  4. The list of issues appears. Click Show on one to jump to it.

Click the toolbar icon on any page that is not a Google Doc to open a demo document. It needs no sign-in.

If something goes wrong

The panel shows a red message when sign-in fails. The common ones:

MessageWhat to do
“Google sign-in isn't set up for this copy of GreenPages” Your copy has a different extension ID from the one Google expects. The message shows your ID; send it in an issue.
“Sign-in didn't finish” Your account is probably not on the tester list yet, or the Google window was closed. Ask to be added, then click Connect again.
“Google refused access to this document (403)” Check that you can open the document and that you are using the account that was approved.
The button never appears Reload the Google Docs tab after installing or updating the extension. The button only appears on an open document, not on the Docs home page.

Remove it

To stop it reading your documents, remove access in your Google account permissions. To stop it running at all, remove it from chrome://extensions.
