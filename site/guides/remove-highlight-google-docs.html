How to remove highlighting in Google Docs

To remove highlighting in Google Docs, select the text and set the highlight colour to None. Highlights look light on screen but can flood a printed page with ink.

Remove it

  1. Select the highlighted text. To clear the whole document, press Ctrl+A (Cmd+A on a Mac).
  2. In the toolbar, click Highlight color (the marker icon). If you do not see it, click the More (three dots) button at the right of the toolbar.
  3. Choose None at the top of the palette.

Another way is Format, then Clear formatting. That removes the highlight but also fonts, sizes and every other style on the selection, so use it with care.

Keep the emphasis without the ink

An underline (Ctrl+U, or Cmd+U) or bold (Ctrl+B, or Cmd+B) marks the same words and uses a tiny fraction of the ink when printed.

Finding every highlight

Docs has no list of highlights, so on a long document it is easy to miss some. Scroll with the page preview, or let a tool find them.

Or let SparePage do it. It lists every highlight in the document, each with an underline as the fix, and shows how much ink it saves. See how to install it.
