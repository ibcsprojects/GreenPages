How to delete a blank page in Word

A blank page in Word usually comes from extra paragraph marks, a manual page break or section break, or a table that ends at the bottom of the last page. Show the paragraph marks and delete what is on the page.

Delete it

  1. On the Home tab, click the paragraph mark button (¶) to show hidden marks. The shortcut is Ctrl+Shift+8 on Windows and Cmd+8 on a Mac.
  2. Find the blank page. You will see paragraph marks, or a line saying Page Break or Section Break.
  3. Select those marks and press Delete. If it was a section break, check the formatting of the page before it afterwards.

If the blank page comes after a table

Word needs a paragraph after a table, and you cannot delete it. If the table reaches the bottom of the page, that paragraph moves to a new page. Select the paragraph mark after the table, set its font size to 1, and set its spacing to 0. It then fits on the table’s page.

If the blank page only appears when you print

Check the printer’s own settings for options such as a separator page or a banner page, which add an extra sheet.
