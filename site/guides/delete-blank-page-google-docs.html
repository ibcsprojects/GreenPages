How to delete a blank page in Google Docs

A blank page in Google Docs is almost always caused by an extra empty paragraph, a page break, or a table at the end of the document. Show the hidden marks, then delete whatever is sitting on that page.

Delete it

  1. Press Ctrl+End (Cmd+Down arrow on a Mac) to jump to the end of the document.
  2. Press Backspace until the blank page goes away. If it does, you are done.
  3. If the page stays, open View and turn on Show non-printing characters. Every paragraph mark and page break now shows.
  4. Click just after the extra mark or the page break on the blank page and press Backspace or Delete.

If the blank page comes after a table

Docs always keeps one empty paragraph after a table, and you cannot delete it. If the table fills the page, that paragraph spills onto a new one. Select the paragraph mark after the table and set its font size to 1, with line spacing set to single. It then fits on the page the table is on. You can also make the table a little shorter.

If only one line spilled over

Check Format, then Line & paragraph spacing, and remove the space after paragraphs. Or open File, then Page setup, and make the bottom margin slightly smaller.

Or let SparePage do it. It finds stacks of blank lines and trailing blank pages and collapses them in one click. See how to install it.
